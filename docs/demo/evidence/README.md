# Visual evidence

The PNG files in this directory are full-page captures generated by
`frontend/tests/storyline.spec.ts` from the deterministic local application,
one per key storyline step (`NN-<scene>-<project>.png`) for the
`desktop-chromium` and `mobile-chromium` projects. Steps 8 and 13 are
exercised by the test but not captured, to keep the review set small.

Captures from a deployed environment (when `DEMO_ACCESS_CODE` is set) are
prefixed with `live-`.

Regenerate them with:

```powershell
Set-Location frontend
npm run build
npx playwright test storyline.spec.ts
```
